# 本地内容编辑器

一个跑在自己电脑上的可视化内容编辑器，用来写 `src/content/posts`（文章）和
`src/content/notes`（手记）。不用登录、不用联网、不用装任何依赖，本质就是
一个很小的本地网页。

## 启动

```bash
pnpm editor          # 等于 node tools/editor/server.mjs
pnpm post            # 等于 node tools/editor/server.mjs --open=new-post，顺手新建一篇
```

或者直接：

```bash
node tools/editor/server.mjs          # 启动，手动打开终端里打印的网址
node tools/editor/server.mjs --open   # 启动后自动打开系统默认浏览器
```

启动后终端会打印完整地址，形如 `http://127.0.0.1:4322/`。

服务只监听 `127.0.0.1`，外网访问不到。端口从 4322 开始，被占用就依次试
4323、4324……直到 4340；实在都被占了会直接报错退出。

## 界面

三栏布局：

- **左栏**：文章 / 手记两个标签页；搜索框（按标题和标签实时过滤）；文档列表
  （标题、日期、草稿标记、标签）。鼠标悬在列表项上会出现删除按钮，删除会二次确认。
  底部是「＋ 新建」。
- **中栏**：frontmatter 表单 + Markdown 正文。标题、日期（可选到分钟）、标签
  （回车或逗号变成 chip）、摘要、封面（可上传本地图片）、草稿开关、置顶（文章）；
  周次、心情（手记）。正文上面是一排 Markdown 工具按钮。
  **封面图文章和手记都能设**（`content.config.ts` 里两边都有 `cover`），
  它就是列表里显示的那张图；正文里插的图片不会被当封面。
- **右栏**：Markdown 实时预览，输入停止 200ms 后刷新。

上传图片时会**先在浏览器里压一道再传**（长边 ≤1600px、转 jpg q0.82；
有透明的保持 png、gif/svg 不动、本来就小的原样传）。这样站点不会因为
一张 8MB 截图变慢。压完会提示「图片已压缩后上传（小了约 xx）」。
实现就在 `ui/app.js` 的 `shrinkImage()` 里 —— 不依赖任何服务端图像库
（这台机器上 sharp / Pillow / ImageMagick / ffmpeg 一个都没有）。

其他细节：

- `Ctrl+S` / `Cmd+S` 保存，右上角也有保存按钮，成功后会弹一个小提示。
- 有未保存的修改时，浏览器标题前面会出现 `●`，关页面会提示。
- 表单一变就把草稿写进 `localStorage`；重新打开同一篇时会问要不要恢复。
- 主题跟随系统，也可以在右上角手动切成 浅色 / 深色 / 自动（记在 localStorage）。
- 完全离线：不加载任何外部字体、图片或 CDN。

## 三个入口

工具栏上三个按钮，各管一件事：

**「页面」—— 整页编辑（改页面就用这个）**

像写文章那边一样的三栏：

- **左栏**：整棵版块树上的每一页（缩进 + 地址），带搜索框；点一下切过去。
- **中栏**：这一页的全部可改项 ——
  名称 / 副标题 / 地址 / 版式 / 封面图，然后是「这一页的内容」块列表
  （文字、图片、链接、子页面、分隔线、两栏、视频、文章、目录、地图 十种，能加能删能上下移），
  其中**地图**块可以分页，每页各自钉塔吊图钉、拖**区域划分线**；划分线一条一个颜色 ——
  「在这里放：」那一排末尾有「线色」（取色块 + R/G/B 数字框，双向同步），
  先挑色再拖线，画完还能在下面清单里逐条改（颜色只收 `#rrggbb`，服务端会卡格式）。
  每页还有两个容易搞混的文本框，占位符里已经写明区别：
  **图片说明**（`<img alt>`，页面上不显示）和**简介**（多行，会以小一号的字显示在地图下方）。
  列表后面接着是「这一页的子版块」：改名、传封面、比例、档位、**像素宽高**、上下换顺序，
  以及两个新增按钮 —— **＋ 加子版块**（普通子版块，站里会给它生成一页）
  和 **＋ 加链接版块**（填名字 / 封面 / 网址，点它直接跳走，站里不为它建页面，
  网址也不会显示在页面上）。每一行下面那个「链接」输入框随时能把一项在两种之间切换。
- **右栏**：这一页的真实预览（抓构建产物，同源塞进 srcdoc）。
  底下「保存并重新构建」＝ 写 `home-boards.json` + 跑一次 `astro build` + 刷新预览。

**「时间轴」—— 编辑右侧那条弧线**

顶栏「时间轴」打开，弹窗是**左边表单、右边实时预览**两列：

- **表单**：选/新建/删除一条轴；名称、左右两侧叫什么历；时间点列表
  （左右 / 日期 / 事件名 / 跳转地址）；时间段列表
  （**挂哪一侧** / 名字 / 起点 / 终点 / 跳转地址）。
  时间段那个「挂哪一侧」有左 / 右 / **两侧都有**三种：同一段年月两边各有各的叫法，
  就加两条、起点终点填一样、各选一侧；两边同名就一条选「两侧都有」。
  时间点和时间段的跳转地址都是可选的，填了页面上那个名字才能点
  （不合规的地址当场标红，服务端也会兜底丢掉）。
- **日期可以直接打数字**：敲 `20230110`，横杠自动补上；`2023/1/10`、
  `2023年1月10日` 粘贴进去也认（全角数字也认）。右边 📅 还是能开系统日历。
  读不出来的写法会把框标红、不写进数据（不会存下 `2023-02-30` 这种）。
- **预览**：改任何字段立刻重画 —— 弧线、刻度、时间段带子（带左右偏移）、
  哪个点和哪个点会合并成一个塔吊、文字怎么排，一眼看到。
  它按页面打开时的默认比例尺画（1 格 ≈ 19 天），合并和间距跟页面上一致，
  区别只是**一次画完整条轴**（编辑要的是全貌，页面上是滚一屏看一段）。
  带链接的点 / 段在预览里是**虚下划线**，不用挨个翻就知道哪些能点。

**「排版」—— 微调位置和大小**

点元素选中，**拖动**改位置；拖**右下角的小方块**自由改宽高（左上角不动，像 PS 的变换框）；
下面还有一排数字：**中心点 X / Y（页面像素坐标）、宽、高、缩放**，填了立刻生效，
拖动时数字也会跟着变。

- **每一块版块、每一张子页面卡都能单独选中单独拖**（锚点：`block-<id>`、`kid-<id>`、
  `pg-<块id>`）。以前点两块之间的空白会选到整个网格（`children`），看着就像「全黏在一起」。
- 存下来的是**相对位移（百分比）+ 像素宽高**：位置用百分比，手机上仍按原版式排、不会飞出去；
  宽高用像素，因为「改成 300 像素宽」只有像素说得清，也不像缩放那样把字一起缩小。
- 这里**只能挪和改大小**，加内容要用「页面」。

**「子版块」—— 整棵树的增删改**

大板块自己的名称/副标题/地址；每个版块改名、改地址、`＋下级`、删除、
`移动到…` 换父级（**id 不变**，文章归类靠 id，地址会跟着树变）。
每一行也有个**「链接」**输入框：填了就变成**链接版块**
（卡片照旧，但点它是打开这个网址，站里不再为它生成页面，网址不显示在页面上）——
链接版块是叶子，它的「＋下级」会禁用，「移动到…」里也不会出现它。
每个版块旁边还有**封面图**：传了图，页面上那张卡片就图铺满、微微半透明、名字压在正中；
没传就是一条扁平的名字条，不摆空图位。还有**「版式」下拉**（竖排 / 三列分区）
和**「改这一页」**（直接跳进「页面」工作台）。

**排版微调**（`排版`）：点元素选中，拖动改位置，拖右下角的小方块缩放。
存的是相对偏移和倍数，所以手机上仍是正常布局。
选「大板块页」时会多出一个**「哪个板块」**下拉 —— 板块有很多个（每层版块一页），
得挑一个具体的当样板，否则只调得到第一个大板块。

## 依赖说明

服务端是零依赖的，只用 Node 内置模块（`node:http` / `node:fs/promises` /
`node:path` / `node:url` / `node:crypto` / `node:child_process`），Node 20 以上都能跑。

Markdown 预览用的是项目里的 `marked`（如果装了的话）。装了就用，没装也不会报错——
预览区会显示「未安装 marked，预览不可用」，编辑和保存一切照常。想要预览就：

```bash
pnpm add -D marked
```

## 文件与接口

- 文章目录：`src/content/posts/*.md`，对应集合 `posts`
- 手记目录：`src/content/notes/*.md`，对应集合 `notes`
- 上传的图片：`public/img/uploads/`，页面里引用 `/img/uploads/xxx.png`

接口都返回 JSON：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/bootstrap` | 站点信息 + 内容类型列表 |
| GET | `/api/list?type=posts` | 该类型的文件列表，按日期倒序 |
| GET | `/api/item?type=posts&file=x.md` | 单个文件的 frontmatter 与正文 |
| POST | `/api/save` | `{ type, file, frontmatter, body }`，`file` 为空则按标题生成文件名 |
| POST | `/api/delete` | `{ type, file }` |
| GET | `/api/boards` | 整棵版块树（`src/data/home-boards.json`） |
| POST | `/api/boards` | 写回整棵树（字段白名单收一遍，先备份 `.bak`） |
| GET | `/api/layout` | 排版微调数据（`src/data/layout.json`） |
| POST | `/api/layout` | 合并写入排版微调数据 |
| GET | `/api/preview?path=/huaya/` | 代理本地预览服务（4321），绕开跨源 |
| POST | `/api/build` | 跑一次 `astro build`（同时只跑一个，返回耗时和日志尾巴） |
| POST | `/api/upload` | `{ name, dataUrl }`，返回 `/img/uploads/...` |
| GET | `/vendor/marked.js` | 转发 `node_modules/marked/lib/marked.esm.js`，没装则 404 |

## 安全边界

虽然只是本地工具，该拦的还是拦：

- `type` 只接受 `posts` / `notes`；`file` 只接受纯文件名（`basename`），出现
  `..`、路径分隔符、绝对路径、控制字符一律 400；解析出的绝对路径必须落在对应内容目录内。
- 保存新文件时如果按标题生成的文件名已存在，返回 **409**，不会静默覆盖已有文章，
  同时给出一个可用的替代文件名（`xxx-2.md`）由前端确认。已有文章（`file` 指向的
  就是它自己）照常可以覆盖保存。
- 上传只接受 `image/png`、`image/jpeg`、`image/gif`、`image/webp`、`image/svg+xml`，
  单张上限 10MB；请求体上限 12MB，超了返回 413。
- 静态资源是白名单映射，不做目录遍历。

## 目录结构

```
tools/editor/
├── server.mjs      # HTTP 服务端：API + 静态资源 + 端口探测（零依赖）
├── ui/
│   ├── index.html  # 三栏界面结构
│   ├── app.js      # 前端逻辑（无构建步骤，浏览器直接跑 ES 模块）
│   └── style.css   # 样式，颜色集中在 CSS 变量里
└── README.md
```

改完 `ui/` 里的东西，刷新浏览器即可生效（服务端对这些文件禁用了缓存）。
改 `server.mjs` 需要 `Ctrl+C` 后重新启动。
