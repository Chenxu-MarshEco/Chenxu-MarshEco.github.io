    版块树

    这里管的是首页那两个大板块和它们下面的整棵树：大板块自己的名称、副标题、地址能改； 每个版块能改名、改地址、往下加子版块，也能用「移动到…」换到别的大板块／版块下面。 换父级**不会改 id**（文章归类靠 id），但地址会跟着树变，除非那一项自己写了地址。 保存后写进 src/data/home-boards.json，重新构建即可生效。

    时间轴

    时间轴是**独立的一份数据**（src/data/timelines.json），可以被好几个页面共用， 一个页面也可以换用别的时间轴。左右两侧分别命名 —— 比如左边「花娅历」、右边「冰室历」， 同一个刻度上两边各挂一个事件，就是双线叙事。 右边是**实时预览**：改一个字段就跟着变，不用先存盘再打开页面看。

    导航 · 分类库

    导航是先在这里建分类、页面再引用：一个大分类（比如「实体」）只录一次， 页面里存的是它的 id —— 所以同一个大分类能给好几个页面用（A 页可能挂「甲·乙」、 B 页挂「甲·丙」），之后改分类内容，那些页面一起跟着变。 页面那边在「页面」工作台的内容块里加「＋ 导航」勾选要用哪几个。

    音乐

    每个页面一份歌单：左边挑页面，右边排这一页的歌。 数据写进 src/data/music.json，音频存在 public/audio/uploads/。

    上传会立刻把文件存进 public/audio/uploads/ 并写进数据文件， 但要点「保存并重新构建」才会出现在网站上；播放顺序是随机的（不按这里的顺序走）； 「第一首」是进入这一页时一定先播的那首，选「不指定」就是进页面随机挑一首。
