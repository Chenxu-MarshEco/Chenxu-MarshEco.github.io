这篇把最常用的写法列一遍，当作速查表。

## 标题

`#` 是一级标题，`##` 是二级，最多到 `######`。文章标题已经在 frontmatter 里写了，正文一般从 `##` 开始。二级和三级标题会自动出现在右侧目录里。

## 强调

- `**粗体**` → **粗体**
- `*斜体*` → *斜体*
- `~~删除线~~` → ~~删除线~~
- `` `代码` `` → `代码`

## 列表

无序列表用 `-`：

- 第一项
- 第二项
  - 缩进两格就是子项

有序列表用数字：

1. 第一步
2. 第二步

## 引用

> 用 `>` 开头就是引用块。
> 适合放摘抄、别人的话，或者需要强调的段落。

## 代码

行内代码用反引号包起来。多行代码用三个反引号，并在后面写上语言名，会有语法高亮：

```javascript
function greet(name) {
  return `你好，${name}`;
}

console.log(greet('世界'));
```

```python
def greet(name):
    return f"你好，{name}"

print(greet("世界"))
```

## 表格

```
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
```

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
| 长一点的内容 | 中 | 123 |

## 链接和图片

链接：`[显示文字](https://example.com)`

图片：`![说明文字](/img/uploads/pic.png)`，路径从 `public/` 目录开始算。用编辑器上传图片的话，路径会自动填好。

## 分割线

三个短横线单独一行就是一条分割线：

---

就这些，够用了。
